# AgroStock

Projeto Integrador de Engenharia de Software para apoiar o controle de
estoque em propriedades rurais.

## Situação atual

O projeto está na fase de levantamento de necessidades, pesquisa com usuários,
modelagem e prototipação. A implementação do código ainda não foi iniciada.
